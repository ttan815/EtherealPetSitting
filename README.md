# EtherealPetSitting
CSUS CSC 190 - 191: A full-stack pet sitting booking system with revenue tracking, notifications, pet &amp; customer management.

## Client

From the `client` directory, install dependencies with `npm install` and run the client commands:

- `npm run dev` starts the client development server.
- `npm run build` builds the client for production.
- `npm run lint` checks the client source.
- `npm run preview` previews a production build.

The server remains an independent package in `server`; install its dependencies and run its scripts from that directory.
